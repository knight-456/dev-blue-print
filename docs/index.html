Start with the stack you want

DevBlueprint is an interactive scaffolding CLI for developers who want a useful project structure without manually assembling the same setup each time.

Choose your framework

Generate a React app for Vite, Next.js, or Create React App.

Choose an architecture

Start with enterprise, modular, or minimal project organization.

Select integrations

Pick from Redux, TanStack Query, Axios, Tailwind CSS, MUI, forms, testing, and more.

Control package versions

Use a version preset, override individual packages, or query npm for current versions.

From command to running app

  1. 1. Run the CLIStart the interactive project setup.
  2. 2. Choose optionsSelect framework, language, architecture, and integrations.
  3. 3. Install and runInstall dependencies and start developing.
npm create devblueprint my-app
cd my-app
npm install
npm run dev

Prefer a non-interactive setup? Use npx create-devblueprint my-app --framework vite --language typescript --architecture modular --integrations redux query axios --yes.

Frequently asked questions

Which frameworks can DevBlueprint scaffold?

It supports Vite, Next.js, and Create React App.

Can I choose TypeScript or JavaScript?

Yes. Choose either language in the interactive prompts or pass the language option to the CLI.

Does it install dependencies automatically?

Dependency installation is optional. Add --install to install during scaffolding.

Where can I find the source or report a problem?

Visit the GitHub repository or open a GitHub issue.
